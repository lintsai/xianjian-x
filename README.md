# 《仙劍X：霧魂殘夢》（Legend of Sword and Fairy X: Mist of Destiny）

> 三皇開天清濁分，九泉脈動繫凡塵。  
> 一壺桂酒江湖夢，十載霧魂宿命人。

《仙劍X：霧魂殘夢》是一款深度融匯 **《仙劍奇俠傳》一至七代及外傳（仙三外傳·問情篇、仙五前傳）完整世界觀與精神脈絡**，並嚴格參照 **《仙劍奇俠傳一》（DOS／98柔情篇）經典 45 度斜視角迷宮探索與 45 度對角回合制戰鬥玩法** 打造的原創仙俠 RPG 網頁遊戲。

## 二、 歷代《仙劍 1~7 與前外傳》世界觀融匯架構

遊戲內建可隨時查閱的 **【六界九泉錄】** 典籍，並將九部仙劍作品的核心設定自然織入原創劇情：

1. **三皇創世與六界秩序（仙三／仙四／仙七）**：盤古精氣神化為伏羲、神農、女媧三皇；三族大戰與絕地天通後形成神、魔、仙、妖、人、鬼六界。
2. **神農九泉核心樞紐（仙六／仙七）**：圍繞九泉之 **【霧魂】**（凝滯時間、開啟十年前時間之隙）、**【寒髓】**（極寒生死本源）、**【毒瘴】**（幽溟教引動之萬毒深淵）與 **【龍潭】**（以宿命記憶碎片締結逆命之契，打破必死宿命）展開。
3. **蜀山地脈與尋仙問情（仙一／仙三外傳·問情篇／仙四）**：蜀山五靈地脈震盪，面對執劍長老蒼溟「寧錯殺不縱妖」的教條，主角團在古劍塚與鎮妖古塔叩問「若修仙必先絕情棄義，長生何益？」。
4. **苗疆巫月與宿命悲歌（仙一／仙二／仙五／仙五前傳）**：棲霞仙島奇門荷花陣、姑蘇比武招親、鎖妖塔崩塌捨身相護、白苗聖姑以鳳凰羽與火麒麟角施展傀儡續命、十年前木劍宿命閉環、水魔獸滅世之戰。

## 三、 完整復刻《仙劍奇俠傳一》經典風格與核心玩法

- **45 度斜視角等距地圖、60FPS 絲滑插值與毛毛蟲跟隨隊列**：支援 **8 向螢幕對齊 WASD／方向鍵（含雙鍵斜走與 45 度走廊／荷花橋自動滑牆）**、**滑鼠點擊 A* 尋路／長按拖曳引導**、**360 度太極虛擬搖桿** 與 **Shift／「疾」鍵御風疾行**，隊友如仙劍一般 60FPS 絲滑緊隨主角身後移動。
- **翻箱倒櫃與隱藏彩蛋**：調查客棧酒罈、木桶、古柳木匣、荷塘寶箱搜刮丹藥暗器；連續敲擊客棧青花水缸 3 次可翻出私房錢暗格；鎮妖塔內更有【沉思鬼】與【冰晶書中仙】經典彩蛋。
- **明雷巡邏遇敵與迷宮機關解謎**：棲霞島擊碎四座奇門石像、隱霧蛇窟扭轉青銅蛇首、鎮妖古塔開啟太陰太陽雙陣樞、火麟洞點亮祝融圖騰、九泉深淵嵌入五靈珠破除魔障。
- **45 度對角回合制戰鬥與十字菱形指令盤**：
  - 左下我方三人斜列背影（瀕死單膝跪地、天罡金環、醉仙殘影、隱蠱半透明）、右上敵陣與巨型首領。
  - 十字四向指令：**【攻】**、**【仙】**、**【合】**、**【物（吃藥／投擲）】**，搭配經典快捷鍵 `A` 圍攻、`F` 最強仙術、`W` 投擲、`D` 防禦、`R` 重複上回合、`Q` 逃跑。
- **武器專屬特質**：
  - **蘇靈汐**佩戴雙劍（雙龍短劍／玉女雙劍）普通攻擊自動 **【二連擊】**！
  - **沈月綾**手持長鞭（紅綾長鞭／金蛇軟鞭／九節雷火鞭）普通攻擊直接 **【橫掃敵方全體】**！
- **飛雲探龍手（妙手偷竊）**：可從各大首領身上偷取稀世珍寶：
  - 赤鬼統領 ➔ `血玲瓏` ｜ 金鱗蛇君 ➔ `雪蛤蟆` ｜ 鎮獄明王 ➔ `金蠶王` ｜ 赤炎火麒麟 ➔ `天香續命露` ｜ 魔統領夜梟 ➔ `試煉果` ｜ 幽溟教主 ➔ `金蠶王`
- **五靈相剋與五靈珠改變【合擊】神召**：
  - 遵循 **水剋火 → 火剋雷 → 雷剋風 → 風剋土 → 土剋水**（150% 破靈重創）。
  - 在「裝備 → 配戴」欄裝上靈珠即可將合擊昇華為神明召喚：玉佛珠 ➔ **【佛法無邊】**、風靈珠 ➔ **【風神】**、雷靈珠 ➔ **【雷神】**、火靈珠 ➔ **【火神】**、土靈珠 ➔ **【山神】**、水靈珠 ➔ **【雪妖】**、五靈融合之聖靈珠 ➔ **【武神·斬破宿命】**！
- **煉蠱皿雙槽合成系統**：
  - `赤蠍毒砂 / 無影毒 / 五毒蠱卵 + 化屍水` ➔ **【隱蠱】**（全隊隱身無敵 3 回合！）
  - `雪蛤蟆 + 試煉果` 或 `天香續命露 + 紫菁玉蓉膏` ➔ **【金蠶王】**（直接升 1 級！）
- **暗器與武器投擲、乾坤一擲、一生九次【酒神】**：
  - 不僅能投擲梅花鏢、雷火珠、血玲瓏，還能把淘汰的鐵劍、青鋒劍直接扔出去破防重創強敵！
  - 醉劍翁親傳 **【酒神】** 消耗一壺酒並傾盡當前全部真氣，打出 `真氣 × 8` 毀天滅地傷害（每局遊戲限用 9 次）。

## 四、 六大章節（10 張探索地圖）與三重結局條件

1. **第一章【臨安晨鐘·棲霞仙蹤】**：`臨安渡·忘憂客棧` ➔ `棲霞仙島·奇門荷花陣`（Boss：赤鬼統領）
2. **第二章【姑蘇煙雨·驚鴻比武】**：`姑蘇城·比武擂台`（Boss：沈月綾單挑）➔ `隱霧蛇窟`（雙 Boss：金鱗蛇君＆銀狐夫人，得風靈珠）
3. **第三章【蜀山雲海·鎖妖問情】**：`蜀山丹霞仙境`（劍塚拔七星磐龍劍）➔ `鎮妖古塔`（Boss：鎮獄明王，得雷靈珠、火靈珠與酒神）
4. **第四章【南詔苗疆·神木煉蠱】**：`白苗聖姑谷`（藍阿蠻入隊得煉蠱皿）➔ `神木火麟洞`（Boss：赤炎火麒麟，得鳳凰羽、麒麟角與土靈珠救治月綾）
5. **第五章【霧魂回夢·龍潭抉擇】**：`霧魂時之隙·十年前南詔`（十年前小陸逍木劍宿命、龍潭古鏡祭壇、Boss：魔統領夜梟，得水靈珠）
6. **終章【水魔滅世·宿命迴響】**：`九泉深淵·拜月水魔祭壇`（五靈合成聖靈珠、決戰點將台自由編隊、終極二連戰：幽溟教主 ➔ 合體·渾沌水魔獸）

### 三重結局分流條件
- 🌌 **【隱藏真結局 · 龍潭春曉】**：以鳳凰羽＋麒麟角請聖姑救醒沈月綾，並集齊至少 4 枚「宿命記憶碎片」於第五章【龍潭古鏡】締結【龍潭逆命契】，打破女媧殉道死劫，四人於臨安桃花下重逢！
- ❄️ **【正統結局 · 雪落天蛇】**：救醒沈月綾但未締結龍潭逆命契。蘇靈汐與水魔獸同歸於盡唯餘天蛇靈杖佇立殘陽，冬雪寒梅下沈月綾撐傘守候（致敬仙劍一原版結局意境）。
- 🍶 **【蒼涼結局 · 回夢遊仙】**：未請聖姑完成續命即直闖深淵決戰。魔劫雖平而故人散盡，陸逍獨坐江舟飲酒望月。
